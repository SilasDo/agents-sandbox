- `notify-opencode2-subagent-filter.md`
  - Description: Design for making notify work on `opencode2` and firing only for top-level sessions. Subagent detection is `parentID` (non-empty ⇒ child), carried by `session.created` on **both** v1 (`payload.properties.info.parentID`) and v2, and by each server's session-list route — so v1 gains the filter too (its earlier dead end was only that the trigger events lack the link). v1's stream has no replay (no `Last-Event-ID`/`?since`), and `session.idle`/`session.status` are the v1 signals. A PR-review round, rebased onto `main`, added `session.step.started` to v2's busy events so a second input request in one turn re-arms and re-notifies (residual gap: two requests inside one step still cannot re-arm), bounded v1's seed command with `-m 30`, and corrected the `StickyErrorEvents` comment (the latch lasts the watcher's lifetime, not until reconnect).
